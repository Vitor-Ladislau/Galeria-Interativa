# Galeria Interativa

## Descrição
Página web de uma galeria de fotografias com navegação
por botões e apresentação automática.

## Tecnologias
- HTML
- CSS
- JavaScript
- Git e GitHub

## Como executar
1. Faça o clone do repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo index.html em um navegador.
